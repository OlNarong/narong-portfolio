NARONG OL — CREATIVE PORTFOLIO (UPGRADED)

WHAT'S INCLUDED
- Public portfolio website with category filters.
- Click image projects to view them in a fullscreen preview.
- Click video projects to play them in a fullscreen player with controls.
- Admin panel for adding, editing and deleting projects.
- Multi-select software tags: Photoshop, Illustrator, Premiere Pro, After Effects,
  Lightroom, InDesign, Audition, Adobe XD, CapCut and All Adobe.
- Live preview before saving.
- Upload image/video files from the admin panel. Uploaded media is stored in IndexedDB
  in the current browser; project details are stored in localStorage.
- You can also use relative paths such as images/poster.jpg or videos/reel.mp4.

HOW TO OPEN
1. Extract this ZIP.
2. Open the folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click index.html and choose Open with Live Server.
5. Open admin.html with Live Server to manage projects.

HOW TO ADD A PROJECT
1. Open admin.html.
2. Enter the project title, category, type and description.
3. Select the software used (multiple choices allowed).
4. Upload an image/video or enter a relative path / video URL.
5. Click Preview project to check it.
6. Click Save project.
7. Refresh index.html to see the project.

VIDEO NOTES
- MP4 (H.264) is the safest browser-friendly format; WebM is also supported.
- A video URL must allow playback/embedding by the browser. Some platforms block direct
  playback; for those, use a direct MP4/WebM file URL or a local project file.
- For best reliability, keep local media inside the images/ and videos/ folders and use
  relative paths (for example videos/my-reel.mp4).

IMPORTANT STORAGE LIMITATION
This is a local starter admin system, not a secure online CMS. Browser uploads and project
data are stored only in the same browser profile and device. They do not automatically
sync to visitors or another computer. If you clear browser site data, locally uploaded
media/project data may be removed. For a shared live admin dashboard, connect a backend,
database, authentication and cloud media storage before publishing.
